# Titanic_eLabs
# Titanic Dataset - Exploratory Data Analysis (EDA)

## Overview
This project performs **Exploratory Data Analysis (EDA)** on the Titanic dataset using Python in a Jupyter Notebook.  
The notebook includes data cleaning, preprocessing, statistical analysis, and multiple visualizations to understand passenger survival patterns.

The analysis is performed on both:
- Training Dataset
- Test Dataset

---

## Objectives
- Understand the structure of the Titanic dataset
- Handle missing and inconsistent data
- Perform preprocessing for analysis
- Discover trends affecting passenger survival
- Create meaningful visualizations

---

## Technologies Used
- Python
- Jupyter Notebook

### Libraries
- `pandas`
- `numpy`
- `matplotlib`
- `seaborn`

---

## Dataset Information
The dataset contains passenger details such as:
- Passenger ID
- Name
- Age
- Gender
- Ticket Class
- Fare
- Cabin
- Embarked Location
- Survival Status

---

## Steps Performed

### 1. Data Loading
- Imported Titanic datasets
- Checked dataset structure and data types

### 2. Data Cleaning
- Handled missing values
- Removed unnecessary columns
- Checked duplicates
- Fixed inconsistent data

### 3. Data Preprocessing
- Converted categorical data where required
- Prepared data for analysis and visualization

### 4. Exploratory Data Analysis (EDA)
Performed statistical and graphical analysis to identify:
- Survival distribution
- Gender-based survival trends
- Passenger class impact
- Age distribution
- Fare analysis
- Correlation between features

---

## Visualizations Included
The notebook contains multiple visualizations such as:

- Count Plots
- Bar Plots
- Histograms
- Box Plots
- Heatmaps
- Pie Charts
- Distribution Plots
- Survival Comparison Charts

---

## Key Insights
Some major findings from the analysis:
- Female passengers had a higher survival rate
- First-class passengers survived more frequently
- Younger passengers had better survival chances
- Fare and passenger class influenced survival probability
